# Triage 标签

这些技能使用五种标准 triage 角色。本文件将这些角色映射到本仓库 issue 跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage` | `needs-triage` | 需要维护者评估此 issue |
| `needs-info` | `needs-info` | 正在等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，已准备好交由 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要由人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色时（例如“应用可交由 AFK agent 处理的 triage 标签”），使用上表中相应的标签字符串。

如需匹配实际使用的标签词汇，请编辑右侧“本仓库跟踪器中的标签”列。
