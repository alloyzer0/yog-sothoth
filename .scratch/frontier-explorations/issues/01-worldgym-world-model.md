# 研究：WorldGym 世界模型作为策略评估环境

Type: research
Status: open
Blocked by:

## Question

能否把 WorldGym 的“动作条件视频世界模型 + VLM 奖励评估”缩小为一个可在本地运行的玩具环境，用于比较两个简单控制策略？

论文：[WorldGym: World Model as An Environment for Policy Evaluation](https://arxiv.org/abs/2506.00613)

重点核查：公开代码/模型、最小显存需求、是否可用 Gym/简单 2D 环境替代真实机器人数据。
